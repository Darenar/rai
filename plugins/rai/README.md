# Rai

Open a research folder and ask Rai what you need to start or resume work. Rai
checks the environment, traces inputs, and shows the next useful action.
It can preview a file move or remote update for review before applying it.

- **Start or resume work.** “Tell me what I need to run this project from a fresh checkout.”
- **Store shared data.** “Find the files this project reads and check whether my shared dataset already has them.”
- **Publish a paper.** “Check whether my local paper matches Overleaf and what would go out on the next push.”
- **Work with references.** “Review these PDFs for Zotero and check whether their attachments synced.”

Keep code and results in project Git, original inputs in a private shared
dataset, manuscript files in Overleaf, and reference PDFs in Zotero. Rai uses
the host's tools and guides you through sign-in when a service is missing.
It reports the checks it completed and the ones that still need verification.
